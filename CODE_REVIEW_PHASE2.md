## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ С ОНБОРДИНГОМ

### 1. **НЕТ ПЕРСОНАЛИЗАЦИИ - БОТ НЕ СПРАШИВАЕТ ИМЯ!**

**Проблема:**
- Бот использует `telegram_user.first_name` из Telegram
- НО не спрашивает "Как тебя зовут?" или "Как тебя называть?"
- Пользователь не может представиться

**Локация:** `src/bot/handlers.py:39-70` (start_command)

**Сценарий провала:**
```
Пользователь (Елизавета в Telegram, но все зовут Лиза):
/start
Бот: Привет, Елизавета!
❌ Неправильное обращение на протяжении всего диалога
```

**Решение:**
- Добавить поле `preferred_name` в User model
- Спрашивать в онбординге: "Как тебя зовут? (или как тебя называть?)"
- Использовать preferred_name вместо first_name

### 2. **СЛИШКОМ ФОРМАЛЬНЫЙ/БЫСТРЫЙ ОНБОРДИНГ**

**Проблема:**
- Сразу после приветствия → правовые вопросы (boundaries, privacy)
- Нет "знакомства" и установления эмоционального контакта
- Пользователь не понимает, что конкретно делать

**Локация:** `src/bot/handlers.py:57-69`

**Текущий flow:**
```
1. WELCOME_MESSAGE (приветствие)
2. ETHICAL_BOUNDARIES (юридические границы)
3. PRIVACY_INTRO (согласие)
4. CONSENT_ACCEPTED (главное меню)
```

**Проблемы:**
- Нет вопроса "Что случилось?" или "Что тебя привело?"
- Нет опции пропустить для тех, кому срочно нужна помощь
- После онбординга - сразу кнопки, а не живой диалог

**Решение:**
```
1. WELCOME_MESSAGE + спросить имя
2. Краткое знакомство с функционалом (с кнопкой "Пропустить - мне срочно!")
3. ETHICAL_BOUNDARIES + PRIVACY (коротко, одним сообщением)
4. Первый вопрос: "Что тебя сюда привело?" с опциями:
   - "Хочу разобраться в ситуации"
   - "Мне тревожно/паника"
   - "Просто смотрю, что тут"
```

### 3. **НЕТ ОПЦИИ ПРОПУСТИТЬ ОНБОРДИНГ**

**Проблема:**

- Нет кнопки "Мне нужна помощь СЕЙЧАС"

**Решение:**
- На шаге с ETHICAL_BOUNDARIES добавить кнопку:
  - "😱 Мне срочно нужна помощь" → сразу в panic mode

### 4. **ОТСУТСТВИЕ ПРИМЕРОВ В ОПИСАНИИ ФУНКЦИЙ**

**Проблема:**
- В CONSENT_ACCEPTED описание абстрактное:
  ```
  😱 Кнопка "Паника!" — если прямо сейчас трясет...
  🕵️‍♀️ Разбор полетов — когда нужно разобраться...
  ```
- Пользователь не понимает КАК КОНКРЕТНО это использовать

**Решение:**
- Добавить конкретные примеры:
  ```
  😱 Паника! — например, он не пишет 5 часов и ты накручиваешь себя
  🕵️‍♀️ Разбор полетов — например, "он сказал 'нам надо поговорить' и пропал"
  ```

### 7. **RETURNING USER EXPERIENCE**

**Проблема:**
```python
if user.onboarding_completed:
    await update.message.reply_text("С возвращением! 👋\n\nЧем могу помочь?")
```

**Недостатки:**
- Безличное приветствие (нет имени)
- Нет контекста (когда был последний раз)
- Не предлагается продолжить предыдущий разговор

**Решение:**
```python
# Получить последнюю conversation
last_conv = get_last_conversation(user)
days_ago = (now - last_conv.started_at).days

if days_ago == 0:
    greeting = f"С возвращением, {preferred_name}! Продолжим?"
elif days_ago < 7:
    greeting = f"Привет, {preferred_name}! Прошло {days_ago} дней. Как дела?"
else:
    greeting = f"Рада видеть, {preferred_name}! Давно не виделись. Что нового?"
```

## 🎯 РЕКОМЕНДАЦИИ ПО АРХИТЕКТУРЕ

### 1. Онбординг state machine
Сейчас онбординг - это простая последовательность. Лучше:
```python
ONBOARDING_STATES = {
    "welcome": ask_name,
    "asked_name": show_features,
    "features": ask_consent,
    "consent": ask_first_need,
    "complete": main_menu
}
```

### 2. Centralized callback routing
Сейчас callbacks разбросаны по разным методам. Лучше:
```python
CALLBACK_HANDLERS = {
    "skip_card": handle_skip_card,
    "back_to_analysis": handle_back_to_analysis,
    # ...
}
```
