## 🏗️ АРХИТЕКТУРА PHASE 3

### Новые модели БД

```python
class Payment(Base):
    """Payment transaction"""
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"))

    # Payment details
    amount = Column(Integer)  # В копейках: 99000 = 990₽
    currency = Column(String(3), default="RUB")
    status = Column(String(20))  # pending, succeeded, canceled

    # YooKassa
    payment_id = Column(String(255))  # ID платежа в ЮKassa
    confirmation_url = Column(String(512))  # Ссылка на оплату

    # Timestamps
    created_at = Column(DateTime, default=datetime.utcnow)
    paid_at = Column(DateTime, nullable=True)


class GratitudeEntry(Base):
    """Gratitude journal entry"""
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"))

    # Content
    content = Column(Text, nullable=False)

    # Timestamps
    created_at = Column(DateTime, default=datetime.utcnow)


class MoodEntry(Base):
    """Mood tracking"""
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey("users.id"))

    # Mood: 1 (😔), 2 (😐), 3 (😊)
    mood = Column(Integer, nullable=False)
    note = Column(Text, nullable=True)

    # Timestamps
    created_at = Column(DateTime, default=datetime.utcnow)
```

## 💰 ОЖИДАЕМАЯ ФИНАНСОВАЯ МОДЕЛЬ

### При 1000 MAU:
- Free пользователей: ~850 (85%)
- Premium пользователей: ~150 (15%)
- **MRR:** 150 × 990₽ = 148,500₽ (~$1,500)

### Затраты:
- API Claude: $300-500/мес
- Хостинг: $50/мес
- ЮKassa комиссия: 2.8% = ~4,200₽
- **Итого затраты:** ~$400-600/мес

### Прибыль:
- **MRR:** $1,500
- **Затраты:** $500
- **Profit:** $1,000/мес

**Break-even:** ~300 Premium пользователей = 3000 MAU
