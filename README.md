# AI Friends - Wellness Companion Bot

**"Твоя карманная подружка"** - Telegram-бот для эмоциональной поддержки и самопомощи

---

## 🎯 О проекте

**AI Friends** - это велнес-компаньон для женщин Gen Z и молодых миллениалов (18-30 лет) в России и СНГ, который помогает справляться с тревожностью, разбираться в отношениях и фокусироваться на себе.

### Проблема, которую мы решаем

- **Высокая тревожность**: Женщины испытывают экзистенциальный стресс, но не готовы идти к терапевту
- **"Российский парадокс"**: Культурная установка "я должна справиться сама" (43%), дороговизна (29%), недоверие к эффективности (27%)
- **Разрыв вовлеченности**: Существующие wellness-приложения "пустые", а AI-компаньоны токсичные

### Наше решение

Telegram-бот, который позиционируется как **инструмент для самопомощи**, а не "терапевт":

✅ **Глубокая память** (Nomi-level) - помнит контекст и прошлые проблемы
✅ **Встроенная виральность** - генерирует стильные "Карточки инсайта" для Stories
✅ **Этические границы** - проактивный отказ от роли терапевта и ERP
✅ **Безопасность** - все данные хранятся в РФ (ФЗ-152)

## 🏗️ Архитектура

### Технологический стек

**Backend:**
- FastAPI (Python) - основной веб-фреймворк
- SQLAlchemy - ORM для работы с БД
- SQLite (MVP) → PostgreSQL (Production)

**AI/LLM:**
- Anthropic Claude 3.5 Sonnet - основная модель для диалога
- Anthropic Claude 3 Haiku - быстрый суммаризатор для памяти (Phase 2)

**Vector Database (Phase 2):**
- ChromaDB (self-hosted) - для RAG-системы долгосрочной памяти

**Image Generation (Phase 3):**
- Stable Diffusion (SDXL) + Custom LoRA
- Pillow - для наложения текста

**Platform:**
- Telegram Bot API (`python-telegram-bot`)

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.10+
- Telegram Bot Token (получить через [@BotFather](https://t.me/BotFather))
- Anthropic API Key (получить на [console.anthropic.com](https://console.anthropic.com))

### Установка

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/yourusername/aifriends.git
cd aifriends
```

2. **Создайте виртуальное окружение:**

```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. **Установите зависимости:**

```bash
pip install -r requirements.txt
```

4. **Настройте переменные окружения:**

```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте ваши ключи:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

5. **Запустите бота:**

```bash
python -m src.main
```

Бот запустится и начнет слушать сообщения!

## 🎨 Tone of Voice

Бот использует тон **"Подружки"**:

✅ **Заботливый**: "Я здесь. Я с тобой 🤲"
✅ **Понимающий**: "То, что ты злишься — это нормально!"
✅ **С юмором**: "И давай договоримся: это не должно быть связано с "ним" 😉"
✅ **Честный**: "Я НЕ терапевт и не буду ставить диагнозы"

❌ **НЕ академичный**: Избегаем "когнитивных искажений", "дисрегуляции"
❌ **НЕ корпоративный**: Избегаем "Добро пожаловать", "Ваш запрос обрабатывается"
❌ **НЕ токсично-позитивный**: Избегаем "Все будет хорошо!", "Улыбнись!"

## 🔐 Безопасность и Compliance

### ФЗ-152 (Персональные данные)

✅ **Явное согласие** - пользователь дает согласие при онбординге
✅ **Прозрачность** - понятная Политика конфиденциальности
✅ **Контроль данных** - кнопка "Удалить мою историю"
✅ **Локализация** - данные хранятся на серверах в РФ (Yandex Cloud)

### Этические границы

Бот **проактивно отказывается** от:
- Роли терапевта (не ставит диагнозы)
- Роли врача (не выписывает лекарства)
- Romantic Roleplay / ERP
- Хранения скриншотов и медиафайлов

При критических ситуациях бот **всегда** предлагает:
📞 **8-800-2000-122** - бесплатная психологическая помощь
