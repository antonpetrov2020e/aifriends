### 2. 🎯 Основные функции (Phase 1 MVP)

#### ✅ Онбординг
- Приветствие с Tone of Voice "подружки"
- Объяснение этических границ
- Согласие на обработку данных (ФЗ-152)

#### ✅ Кнопка "Паника!" 😱
- Немедленное успокаивающее сообщение
- Дыхательное упражнение (4-4-4-4)
- Предложение выговориться

#### ✅ Разбор полетов 🕵️‍♀️
- Выбор ситуации (не пишет, поссорились, странное сообщение)
- Структурированный диалог без скриншотов
- Выбор чувств (злость, обида, тревога, растерянность)
- Валидация эмоций
- Наводящие вопросы (Socratic method)

#### ✅ Настройки ⚙️
- Информация о боте
- Удаление истории
- Premium (заглушка для Phase 3)

#### ✅ Freemium модель
- 3 бесплатных "Разбора полетов" в неделю
- Безлимитная кнопка "Паника!"
- Трекинг использования

### 3. 🗄️ База данных

**Модели:**
- `User` - пользователи с согласием и статусом
- `Conversation` - сессии диалога
- `Message` - отдельные сообщения
- `Memory` - извлеченные воспоминания (для Phase 2)
- `InsightCard` - созданные карточки (для Phase 3)

**Хранение:** SQLite (MVP) → PostgreSQL (Production)

### 4. 🔐 Безопасность

✅ **ФЗ-152 Compliance:**
- Явное согласие пользователя
- Прозрачная политика конфиденциальности
- Возможность удалить историю
- Локализация данных (готовность к Yandex Cloud)

✅ **Этические границы:**
- Проактивный отказ от роли терапевта
- Отказ от ERP/романтизации
- Контакт горячей линии при критических ситуациях

✅ **Безопасность данных:**
- Не храним скриншоты/медиа
- Не храним данные третьих лиц
- Минимизация собираемых данных

## 🚀 Как запустить

### Быстрый старт (5 минут)

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd aifriends

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Установить зависимости

# 4. Настроить .env
cp .env.example .env
# Отредактировать .env (добавить токены)

# 5. Запустить
python -m src.main
```

## 🆘 Troubleshooting

### Бот не запускается

**Ошибка**: `No module named 'telegram'`
**Решение**: `pip install -r requirements.txt`

**Ошибка**: `Invalid token`
**Решение**: Проверьте `.env`, правильно ли указан `TELEGRAM_BOT_TOKEN`

**Ошибка**: `Anthropic API key not found`
**Решение**: Проверьте `.env`, добавьте `ANTHROPIC_API_KEY`

### Бот не отвечает

1. Убедитесь, что бот запущен (смотрите терминал)
2. Проверьте логи в терминале
3. Убедитесь, что пишете правильному боту в Telegram
4. Проверьте интернет-соединение

### База данных не создается

**Решение**: Убедитесь, что есть права на запись в текущей директории
